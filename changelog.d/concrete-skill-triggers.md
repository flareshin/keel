### Changed

- The `description:` of `improving-agents`, `descending-findings`, `improving-structure`, `deepening-prompts` and `authoring-agents` now names a moment an agent can observe in ordinary work (a rerun of a subagent whose earlier run failed the same way, a NEEDS_FIXES finding of a kind already fixed in the chain, a `recurring_findings` key in `keel measure weekly`, a request to clean up, simplify or lighten code, a dispatch whose prompt is the owner's one-line words) in place of a judgment about the owner's corrections, so these skills load in normal sessions.
