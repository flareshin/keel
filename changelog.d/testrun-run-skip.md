### Fixed

- `keel test` reads a long output line that ends like a runner summary in linear time. 1.1.6 still read such a line in quadratic time when it held no summary or held one after a long tally run: `'1 a, '` repeated 20,000 times before `x in 1s` took about 22 s, the same run before a jest `, 5 total` or vitest `(3)` ending 9 to 13 s, and a summary inside a TAP `# ` diagnostic 2.5 s; each now takes a few milliseconds. The summary patterns are unchanged; a start inside a tally run that already failed is skipped, and the TAP-diagnostic check runs only once a summary matched, skipping the rest of a `# ` diagnostic. What is counted is unchanged (403,021 generated and captured outputs read the same as 1.1.6). A run of thousands of `=` with no blank after it is still read in quadratic time, about 0.35 s for 20,000.
