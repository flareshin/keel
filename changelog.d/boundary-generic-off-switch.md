### Added
- `boundary/generic-off.txt` in the overlay: one private-address rule name per line (`private-ipv4-10`, `private-ipv4-172`, `private-ipv4-192`), and those rules are not applied in `--generic-only` scans, the scan git-guard runs on every commit in every other repository. A private repository's deployment configuration names its hosts by private addresses, so every edit to such a line was denied as a secret with nothing in the overlay to allow it; an overlay whose repositories hold such lines on purpose now names the address rules there, as `examples/ledger-smoke/boundary/generic-off.txt` shows. Scans with the lexicon (`githooks/pre-commit`, `githooks/pre-push`, smoke `boundary`) keep every generic rule, so the overlay cannot let a private address into keel itself. Any other name in the file is a usage error (exit 2), which git-guard turns into a deny of the guarded command until the file is fixed.
